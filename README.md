# FORME — Furniture Store

A responsive, single-page luxury furniture storefront.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload all four files (`index.html`, `style.css`, `script.js`, `README.md`) to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then press **Save**.
5. Wait a minute or two. Your site address will be:
   `https://thebaqerzade-maker.github.io/.forme-shop/`

## Notes
This is a front-end demo. Product images are loaded from Unsplash. Cart interactions work in the browser, but payment, inventory, accounts, and order management are not connected.
